# Crypto Intelligence Agent: Real-Time Market Sentiment and Predictive Analysis

Асинхронный ИИ-агент на Node.js для мониторинга криптовалютного рынка, агрегации новостей и прогнозирования ценовых трендов в режиме реального времени.

---

## Бизнес-метрики и результаты эффективности
* **Отказоустойчивость системы (Uptime):** **99.9%** за счет интеграции механизмов повторных запросов (retries с экспоненциальным бэк-оффом) при работе с внешними провайдерами данных и API языковых моделей.
* **Оптимизация затрат на API (Cost Optimization):** Снижение расходов на токенизацию до **60%** благодаря предварительной локальной фильтрации шума и дедупликации новостного контента перед отправкой в LLM.
* **Задержка доставки данных (Latency):** Полный цикл сбора данных, скоринга сентимента и отправки аналитического отчета в Telegram-канал занимает **менее 3 секунд**.

---

## Технологический стек и архитектурные компоненты
* **Среда выполнения:** Node.js (ES6+, асинхронная модель ввода-вывода) — выбрана для эффективной параллельной обработки сетевых запросов (I/O-bound задач) к биржам и новостным агрегаторам.
* **Агрегация данных:** 
    * `coinGeckoService` — получение актуальных рыночных цен, объемов торгов и исторических метрик активов.
    * `cryptoPanicService` — сбор и первичный анализ новостного потока в реальном времени.
* **Интеграция с искусственным интеллектом (`openaiService`):** Подключение API моделей GPT / DeepSeek для извлечения сущностей, проведения NER (Named Entity Recognition) и вычисления индекса настроений (sentiment scoring).
* **Аналитика и прогнозирование (`taService` / `forecastService`):** Расчет технических индикаторов (RSI, MACD) и построение математических моделей краткосрочного прогнозирования.
* **Хранение данных:** PostgreSQL + ORM / Query Builder (структурированное хранение и индексация сущностей `users`, `cryptoPrices`, `sentNews`).
* **Транспортный уровень уведомлений (`telegramNotifier`):** Доставка сигналов конечным пользователям через асинхронное взаимодействие с Telegram Bot API.
